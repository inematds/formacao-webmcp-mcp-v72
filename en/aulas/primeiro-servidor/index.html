Lesson 2 · 20 min

First stdio server with the official SDK, tested in the Inspector

The simplest way to connect a service to an agent is stdio: the client starts your program and talks to it over stdin and stdout. In this lesson you install the kit with pinned versions, read the class server, and call the tool two ways: with a test client and with the MCP Inspector in command-line mode.

Start the lesson

In this lesson you will

  1. 1Install the kit with npm ci and check the versions
  2. 2The createServer factory and the SDK v2 serveStdio
  3. 3Call the tool through Inspector 2.11.0 in --cli mode
  4. 4Why every log goes to stderr

Goal: start an MCP server over stdio with the official v2 SDK and call it with a test client and with the Inspector, no host at all.

03 · The classes server

Read before you run. The two tools, the resource, and the prompt are in the same factory; stdio is just the front door.

File · kit/servidor.mjs
// servidor.mjs — the course's example MCP server (a fictional class service).
// Official SDK v2 (@modelcontextprotocol/server 2.3.1, from 05/10/2026), which serves the
// 2026-07-28 MCP revision and, with the same code, clients on the 2025-11-25 revision.
// It calls no model or paid service: the data stays in the process memory.
import { McpServer, acceptedContent, inputRequired, inputResponse, requireScopes } from '@modelcontextprotocol/server';
import * as z from 'zod/v4';

export const TURMAS = [
  { id: 'html-01', titulo: 'HTML semântico para agentes', vagas: 3 },
  { id: 'mcp-01', titulo: 'Servidor MCP em uma tarde', vagas: 1 },
  { id: 'mcp-02', titulo: 'MCP com autorização', vagas: 0 }
];

const Turma = z.object({ id: z.string(), titulo: z.string(), vagas: z.int() });
const Confirma = z.object({ confirmar: z.boolean().meta({ title: 'Confirmar a reserva' }) });

export function createServer() {
  const server = new McpServer({ name: 'turmas', version: '1.0.0' });

  // 1) Read-only tool: the client can approve it without asking.
  server.registerTool(
    'buscar_turmas',
    {
      title: 'Buscar turmas',
      description: 'Lista turmas cujo título contém o termo. Só leitura: não reserva nada.',
      inputSchema: z.object({
        termo: z.string().min(2).describe('Parte do título, ex.: "mcp"'),
        limite: z.int().min(1).max(20).optional().describe('Máximo de turmas (padrão 5)')
      }),
      outputSchema: z.object({ turmas: z.array(Turma) }),
      annotations: { readOnlyHint: true, idempotentHint: true, openWorldHint: false }
    },
    async ({ termo, limite }) => {
      const t = termo.toLowerCase();
      const turmas = TURMAS.filter(x => x.titulo.toLowerCase().includes(t)).slice(0, limite ?? 5);
      return {
        content: [{ type: 'text', text: turmas.map(x => `${x.id} · ${x.titulo} · ${x.vagas} vagas`).join('\n') || 'nenhuma turma' }],
        structuredContent: { turmas }
      };
    }
  );

  // 2) Tool with consequences: asks the user for confirmation mid-call (MRTR).
  server.registerTool(
    'reservar_vaga',
    {
      title: 'Reservar vaga',
      description: 'Reserva uma vaga na turma para o e-mail informado. Tem consequência: pede confirmação antes.',
      inputSchema: z.object({
        turma_id: z.string().describe('Id da turma, ex.: "mcp-01"'),
        email: z.email().describe('E-mail de quem vai fazer a turma')
      }),
      annotations: { readOnlyHint: false, destructiveHint: false, idempotentHint: false, openWorldHint: false },
      // With a token (http-auth.mjs), it requires the turmas:reservar scope; without a token (stdio), it does not apply.
      scopeChallenge: requireScopes('turmas:reservar')
    },
    async ({ turma_id, email }, ctx) => {
      const turma = TURMAS.find(x => x.id === turma_id);
      if (!turma) return { content: [{ type: 'text', text: `turma ${turma_id} não existe` }], isError: true };
      if (turma.vagas < 1) return { content: [{ type: 'text', text: `turma ${turma_id} sem vagas` }], isError: true };

      const resposta = inputResponse(ctx.mcpReq.inputResponses, 'confirmar');
      if (resposta.kind === 'elicit' && resposta.action !== 'accept') {
        return { content: [{ type: 'text', text: 'reserva cancelada pelo usuário' }], isError: true };
      }
      const ok = acceptedContent(ctx.mcpReq.inputResponses, 'confirmar', Confirma);
      if (ok?.confirmar !== true) {
        return inputRequired({
          inputRequests: {
            confirmar: inputRequired.elicit({ message: `Reservar 1 vaga em "${turma.titulo}" para ${email}?`, requestedSchema: Confirma })
          }
        });
      }
      turma.vagas -= 1;
      return { content: [{ type: 'text', text: `reservado: ${turma_id} para ${email} (restam ${turma.vagas})` }] };
    }
  );

  // 3) Resource: data the client reads whenever it wants (not an action).
  server.registerResource(
    'catalogo',
    'turmas://catalogo',
    { title: 'Catálogo de turmas', description: 'Todas as turmas em JSON', mimeType: 'application/json' },
    async uri => ({ contents: [{ uri: uri.href, mimeType: 'application/json', text: JSON.stringify(TURMAS) }] })
  );

  // 4) Prompt: a request template the user picks in the client.
  server.registerPrompt(
    'convite_turma',
    {
      title: 'Convite para a turma',
      description: 'Monta o pedido de um convite curto para uma turma',
      argsSchema: z.object({ turma_id: z.string() })
    },
    async ({ turma_id }) => ({
      messages: [{ role: 'user', content: { type: 'text', text: `Escreva um convite de 3 linhas para a turma ${turma_id}, usando o recurso turmas://catalogo.` } }]
    })
  );

  return server;
}

// stdout is the protocol channel: every log goes to stderr (console.error).
import { serveStdio } from '@modelcontextprotocol/server/stdio';
import { createServer } from './servidor.mjs';

serveStdio(createServer);
console.error('turmas: servidor MCP no stdio');

File · kit/teste-stdio.mjs
// Usage: node teste-stdio.mjs [server file, default stdio.mjs]
// teste-stdio.mjs — plays the role of the client (Claude Code, Codex…): starts "node stdio.mjs",
// negotiates the protocol revision, and calls a tool through the process's stdin/stdout.
import { Client } from '@modelcontextprotocol/client';
import { StdioClientTransport } from '@modelcontextprotocol/client/stdio';

const cliente = new Client({ name: 'teste-stdio', version: '1.0.0' }, { versionNegotiation: { mode: 'auto' } });
await cliente.connect(new StdioClientTransport({ command: 'node', args: [process.argv[2] ?? 'stdio.mjs'] }));
const { tools } = await cliente.listTools();
const r = await cliente.callTool({ name: 'buscar_turmas', arguments: { termo: 'mcp' } });
console.log(`era: ${cliente.getProtocolEra()} · ferramentas: ${tools.map(t => t.name).join(', ')}`);
console.log(`buscar_turmas → ${r.structuredContent.turmas.length} turmas`);
await cliente.close();

06 · stdout belongs to the protocol

On stdio, every line of stdout is read as a JSON-RPC message. That's why the kit logs with console.error (stderr). The SDK documentation warns that a console.log corrupts the channel and the host may drop the connection.

In our test on 10/19/2026, the SDK 2.3.1 client and Inspector 2.11.0 skipped a stray line and kept going. Don't count on that: another host may not be so forgiving. Always log to stderr.

Prefer Python? The official SDK package mcp 2.3.0 (PyPI, downloaded on 10/19/2026) contains server/discover and InputRequiredResult in its code; check the python-sdk release notes before using it. This course stays with Node; the concepts apply equally.
