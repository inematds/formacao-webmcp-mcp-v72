Aula 3 · 20 min

Desenhar boa ferramenta: nome, descrição, JSON Schema, idempotência, só-leitura × com consequência

O modelo escolhe a ferramenta lendo nome, descrição e esquema; o cliente decide se pede aprovação lendo as anotações. Ferramenta mal desenhada é chamada na hora errada ou com argumento errado. Nesta aula você confere, com um script, se as suas ferramentas dizem o que fazem e o que mudam.

Começar a aula

Nesta aula você vai

  1. 1Uma intenção por ferramenta, com nome e descrição que a dizem
  2. 2Esquema de entrada que recusa o argumento errado antes do seu código
  3. 3As quatro anotações e o padrão quando você não diz nada
  4. 4Resultado em texto e estruturado; erro que o modelo consegue ler

Objetivo: escrever nome, descrição, esquema e anotações que deixam o agente escolher certo e o cliente pedir confirmação quando há consequência.

01 · O que o modelo e o cliente leem

Clique em cada parte do registro de uma ferramenta.

Clique em cada bloco do diagrama para ver o que ele faz.

Semântica das anotações conforme o tipo ToolAnnotations da revisão 2026-07-28 (código do SDK oficial, 13/10/2026).

02 · Anotações: o que significa não dizer nada

Os padrões da especificação valem quando você omite a anotação.

1. readOnlyHint

true = a ferramenta não muda o ambiente. Um host pode aprovar sozinho uma ferramenta só de leitura.

Sem a anotação, o cliente deve supor que ela muda algo.

2. destructiveHint

Só faz sentido quando não é só leitura. true = pode apagar ou sobrescrever; false = só acrescenta (como uma reserva nova).

Omitir numa ferramenta que muda algo = o cliente trata como destrutiva.

3. idempotentHint

true = repetir com os mesmos argumentos não tem efeito extra. Importa porque clientes repetem chamadas (rede caiu, MRTR na aula 5).

reservar_vaga não é idempotente: duas chamadas, duas vagas.

4. openWorldHint

true = fala com o mundo externo (busca na web, API de terceiro). false = domínio fechado, como o catálogo em memória do kit.

Ferramenta de mundo aberto é porta de entrada de conteúdo não confiável: o curso 4 trata disso.

04 · Confira o desenho com um script

Lista as ferramentas, confere descrição e anotação, chama com argumento bom e com argumento ruim.

Terminal · conferir ferramentas
cd ~/projetos/formacao-webmcp-mcp-v72/kit
node teste-ferramentas.mjs; echo "saída: $?"
Arquivo · kit/teste-ferramentas.mjs
// teste-ferramentas.mjs — confere o desenho das ferramentas: anotações, argumento válido,
// argumento inválido (o SDK recusa antes do seu código rodar) e resultado estruturado.
import { Client, StreamableHTTPClientTransport } from '@modelcontextprotocol/client';
import { createMcpHandler } from '@modelcontextprotocol/server';
import { createServer } from './servidor.mjs';

const handler = createMcpHandler(createServer);
const cliente = new Client({ name: 'teste-ferramentas', version: '1.0.0' }, { versionNegotiation: { mode: 'auto' } });
await cliente.connect(new StreamableHTTPClientTransport(new URL('http://teste.local/mcp'),
  { fetch: (url, init) => handler.fetch(new Request(url, init)) }));

let falhas = 0;
const confere = (ok, msg) => { console.log(`${ok ? 'ok   ' : 'FALHA'} ${msg}`); if (!ok) falhas++; };

const { tools } = await cliente.listTools();
for (const t of tools) {
  confere(t.description?.length >= 20, `${t.name}: descrição com 20+ caracteres`);
  confere(typeof t.annotations?.readOnlyHint === 'boolean', `${t.name}: diz se é só leitura`);
}
const ok = await cliente.callTool({ name: 'buscar_turmas', arguments: { termo: 'mcp', limite: 1 } });
confere(ok.structuredContent?.turmas?.length === 1, 'buscar_turmas devolve structuredContent com 1 turma');
const ruim = await cliente.callTool({ name: 'buscar_turmas', arguments: { termo: 'm' } });
confere(ruim.isError === true, `argumento inválido vira isError: ${ruim.content[0].text.slice(0, 70)}…`);

console.log(`${falhas} falhas`);
await cliente.close();
await handler.close();
process.exitCode = falhas ? 1 : 0;

ok    reservar_vaga: descrição com 20+ caracteres

ok    argumento inválido vira isError: Input validation error: Invalid arguments for tool buscar_turmas: term…
